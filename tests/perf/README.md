# S3Sweep Performance Tests

Comprehensive performance testing suite for s3sweep workers.

## Test Categories

### Benchmark Tests (`benchmark.sh`)

Throughput and latency performance tests:

- **PERF-001**: Single worker, small files (1KB)
- **PERF-002**: Single worker, large files (100MB)
- **PERF-003**: 3 workers, mixed file sizes
- **PERF-004**: 10 workers throughput
- **PERF-005**: Find saturation point (scale testing)
- **PERF-006**: Job claim latency
- **PERF-007**: Contention latency (10 workers, 1 job)
- **PERF-008**: End-to-end latency
- **PERF-009**: Idle polling overhead

### Resource Monitoring (`resource_monitor.sh`)

Memory and CPU usage tests:

- **PERF-010**: Memory usage (idle)
- **PERF-011**: Memory usage (active)
- **PERF-012**: CPU usage (idle)
- **PERF-013**: CPU usage (active)
- **PERF-014**: Memory leak detection (1000 jobs)

### Stress Tests (`stress.sh`)

High-load and endurance tests:

- **PERF-015**: 10K jobs with 5 workers
- **PERF-016**: 100K jobs with 10 workers
- **PERF-017**: Sustained load (1 hour continuous)
- **PERF-018**: Burst load (1K jobs instantly)

## Usage

### Run All Benchmarks

```bash
cd tests/perf
./benchmark.sh
```

### Run Resource Monitoring

```bash
./resource_monitor.sh
```

### Run Stress Tests

```bash
# All stress tests (except sustained)
./stress.sh

# Specific stress test
./stress.sh 10k
./stress.sh 100k
./stress.sh burst
./stress.sh sustained  # 1 hour test
```

### Analyze Results

```bash
# Generate summary report
python3 analyze.py

# View results
cat /tmp/s3sweep_perf_summary.md
```

## Output Files

All test results are written to `/tmp/`:

- `/tmp/s3sweep_perf_results.txt` - Benchmark results
- `/tmp/s3sweep_resource_results.txt` - Resource monitoring results
- `/tmp/s3sweep_stress_results.txt` - Stress test results
- `/tmp/s3sweep_perf_summary.md` - Analyzed summary (generated by analyze.py)

## Configuration

### Environment Variables

- `RESULTS_FILE` - Override default results file location
- `MOCK_S3` - Enable/disable mock S3 (default: true)
- `RCLONE_BIN` - Path to rclone binary (default: rclone)

### Test Data

Test data is generated in `/tmp/s3sweep_perf_test/` or `/tmp/s3sweep_stress_test/`:

```
/tmp/s3sweep_*_test/
├── jobs/           # Job files
├── results/        # Worker results
├── data/           # Test files
└── downloads/      # Downloaded files
```

## Interpreting Results

### Status Codes

- **PASS** ✅ - Result within 20% of baseline
- **WARN** ⚠️ - Result exceeds baseline by 20-50%
- **FAIL** ❌ - Result exceeds baseline by >50%

### Common Issues

**Low throughput:**
- Check disk I/O performance
- Verify network connectivity to S3
- Increase worker count

**High memory usage:**
- Check for memory leaks (PERF-014)
- Reduce file size or parallelism
- Verify rclone flags

**High CPU idle:**
- Job queue may be empty
- Increase job generation rate
- Check job distribution

## Requirements

- Bash 4.0+
- bc (for calculations)
- Python 3.8+ (for analyze.py)
- rclone (for actual S3 tests)
- 1GB+ free disk space (for test data)

## Notes

- Mock mode (default) simulates S3 operations using local file copies
- For real S3 testing, set `MOCK_S3=false` and configure rclone.conf
- Sustained load test (PERF-017) runs for 1 hour - use with caution
- Memory leak detection requires sufficient test duration (1000+ jobs)

## Troubleshooting

**"rclone not found"**
```bash
# Install rclone
brew install rclone  # macOS
apt install rclone   # Ubuntu
```

**"bc: command not found"**
```bash
brew install bc      # macOS
apt install bc       # Ubuntu
```

**Permission denied**
```bash
chmod +x *.sh
```

**Disk space issues**
```bash
# Clean up test data
rm -rf /tmp/s3sweep_*_test/
```
