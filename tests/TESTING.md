## Quick Start

```bash
# Run all integration tests (with setup and cleanup)
cd tests/integration
./run_all_tests.sh

# Run specific test suite
./test_e2e.sh          # End-to-end tests
./test_multiworker.sh  # Multi-worker tests

# Skip environment setup (use existing)
SKIP_SETUP=true ./run_all_tests.sh

# Skip cleanup (for debugging)
SKIP_CLEANUP=true ./run_all_tests.sh
```

## Test Structure

```
tests/
├── TESTING.md                    # This file
├── lib/                          # Shared test libraries
│   ├── helpers.sh                # Common helper functions
│   └── assertions.sh             # Test assertion utilities

    ├── setup.sh                  # Environment setup

    └── testdata/                 # Generated test files
```

## Running Tests

### Local Development

#### Full Test Suite

```bash
# Start fresh (setup + run + cleanup)
cd tests/integration
./run_all_tests.sh
```

#### Individual Test Suites

```bash
# E2E tests only
./test_e2e.sh

# Multi-worker tests only
./test_multiworker.sh
```

#### Development Workflow

```bash
# 1. Start environment (once)
docker-compose up -d
./setup.sh

# 2. Run tests repeatedly (fast)
SKIP_SETUP=true SKIP_CLEANUP=true ./run_all_tests.sh

# 3. Debug specific test
bash -x ./test_e2e.sh  # With debug output

# 4. Cleanup when done
docker-compose down -v
```

### Continuous Integration

Tests run automatically on GitHub Actions for:
- Push to `main` or `develop` branches
- Pull requests to `main` or `develop`
- Manual workflow dispatch

**Workflow file**: `.github/workflows/integration-tests.yml`

**Jobs**:
1. `integration-tests` - Uses GitHub service containers
2. `docker-integration` - Uses docker-compose

## Writing Tests

### Test Function Template

```bash
#!/bin/bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
source "$SCRIPT_DIR/../lib/helpers.sh"
source "$SCRIPT_DIR/../lib/assertions.sh"

#######################################
# INT-XXX: Test description
# Scenario: What you're testing
# Expected: Expected outcome
#######################################
test_my_feature() {
    test_section "INT-XXX: My Feature"

    setup_test_env

    # Test setup
    local job_id="job-test-001"
    local dst_path="${TEST_DATA_DIR}/test.txt"
    create_job "${job_id}" "${job_id}|s3test|bucket/path|${dst_path}"

    # Test execution
    test_info "Running test operation..."
    # ... your test logic ...

    # Assertions
    assert_file_exists "${dst_path}" && \
    assert_job_succeeded "${job_id}"

    local result=$?
    cleanup_test_env
    return $result
}

main() {
    reset_assertions
    test_my_feature || ((failed++))
    print_assertion_summary
}

main "$@"
```

### Available Test Helpers

#### Environment Management

```bash
setup_test_env()              # Create temp dirs, config
cleanup_test_env()            # Clean up temp environment
create_job(name, content)     # Create job in pending/
```

#### Assertions

```bash
assert_file_exists(path)                    # File must exist
assert_file_not_exists(path)                # File must not exist
assert_file_in_dir(filename, dir)           # File in specific dir
assert_job_succeeded(job_name)              # Job in done/
assert_job_failed(job_name)                 # Job in failed/
assert_checksum_match(file1, file2)         # Files identical
assert_equals(actual, expected)             # Values equal
assert_greater_than(actual, threshold)      # Numeric comparison
assert_contains(haystack, needle)           # String contains substring
assert_log_contains(pattern)                # Log contains pattern
assert_dir_exists(path)                     # Directory exists
assert_dir_empty(path)                      # Directory is empty
```

#### Logging

```bash
test_section(title)     # Print section header
test_info(message)      # Info message (green)
test_error(message)     # Error message (red)
```

#### Counters

```bash
reset_assertions()           # Reset assertion counters
print_assertion_summary()    # Print pass/fail summary
```

### Test Naming Convention

Format: `INT-XXX: Description`

**Number Ranges**:
- `INT-001` to `INT-008`: E2E basic operations
- `INT-009` to `INT-015`: Multi-worker scenarios
- `INT-016` to `INT-020`: Network chaos (planned)
- `INT-021` to `INT-025`: Large files (planned)
- `INT-026` to `INT-030`: Credentials (planned)

## Test Infrastructure

### MinIO

S3-compatible object storage for testing.

```bash
# Access MinIO Console
open http://localhost:9001
# Login: minioadmin / minioadmin

# CLI operations
mc alias set s3sweep-local http://localhost:9000 minioadmin minioadmin
mc ls s3sweep-local/s3sweep-test
```

### Toxiproxy

Network chaos testing (latency, timeouts, connection issues).

```bash
# List proxies
curl http://localhost:8474/proxies

# Add 1s latency
curl -X POST http://localhost:8474/proxies/minio/toxics \
  -d '{"type":"latency","attributes":{"latency":1000}}'

# Remove toxic
curl -X DELETE http://localhost:8474/proxies/minio/toxics/latency
```

### Test Data

Generated by `setup.sh`:

| File | Size | Purpose |
|------|------|---------|
| `test.txt` | 27B | Small text file |
| `file_1kb.bin` | 1KB | Small binary |
| `file_1mb.bin` | 1MB | Medium binary |
| `file_100mb.bin` | 100MB | Large binary |

## Debugging

### View Test Logs

```bash
# Worker logs (during test)
cat /tmp/s3sweep-test.*/worker.log

# Test output with debug
bash -x tests/integration/test_e2e.sh
```

### Check Test Environment

```bash
# MinIO status
curl http://localhost:9000/minio/health/live

# List test bucket
rclone ls s3test:s3sweep-test --config tests/integration/rclone.conf

# Docker logs
docker-compose logs minio
docker-compose logs toxiproxy
```

### Common Issues

**Port conflicts**:
```bash
# Check what's using port 9000
lsof -i :9000

# Change ports in docker-compose.yaml
```

**MinIO not ready**:
```bash
# Restart services
docker-compose restart minio

# Check logs
docker-compose logs -f minio
```

**rclone config**:
```bash
# Regenerate config
rm tests/integration/rclone.conf
./tests/integration/setup.sh
```
